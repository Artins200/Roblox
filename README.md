# ДРОНЫ — арена над бездной

Многопользовательская Roblox-игра: **меню → голосование за режим → раунд на случайной карте**.
Четыре режима, четыре карты, дроны с настоящей физикой полёта, выжившие с винтовками,
ножами и строительством из досок.

Открыть: **`VolcanoDrone.rbxlx`** в Roblox Studio → **Play**.

## Как это играется

1. Заходите — видите меню «ДРОНЫ» и карточки режимов с голосами.
2. **НАЧАТЬ ИГРУ** → «ЗА КОГО ХОТИТЕ ИГРАТЬ?» (дрон / выживший / по режиму / случайно) → **В БОЙ**.
3. Голосование идёт 25 секунд, потом стартует раунд на **случайной карте**.
4. Через 15 минут (или как только выполнено условие победы) — итоги, новое голосование, новая карта.

## Режимы

| Режим | Кто против кого | Победа |
|---|---|---|
| **ПРЯТКИ** | один дрон ищет всех остальных | дрон нашёл всех / прячущиеся дожили до конца (соло — собрать 6 маяков) |
| **КОМАНДА НА КОМАНДУ** | красные дроны против синих, у каждого есть тимейты | 30 фрагов или больше фрагов к концу времени |
| **СВОБОДНЫЙ ПОЛЁТ** | все на дронах без правил | просто летайте и тренируйтесь |
| **ВЫЖИВШИЕ** | отряд с винтовками и досками против дронов | выжившие дожили до конца / дроны выбили всех |

Ботов сервер добирает сам, поэтому любой режим играбелен даже в одиночку.

## Карты

| Карта | Что внутри |
|---|---|
| **ЛАВОВЫЙ КАНЬОН** | лавовое море, водопады, острова на цепях, замок, ~1600 деталей |
| **ПЕСЧАНЫЕ РУИНЫ** | мёртвый город, месы, арки, песчаные дюны и пыль |
| **ЛЕДЯНЫЕ ШПИЛИ** | замёрзшее озеро, кристаллы, станция, снегопад |
| **ОРБИТАЛЬНАЯ СТАНЦИЯ** | неоновое кольцо, модули, солнечные панели, пустота под ногами |

Карты лежат в `ServerStorage.Maps` и клонируются в `Workspace` на старте раунда; свет,
туман и атмосфера переключаются под карту.

## Управление

**Дрон:** WASD — крен/тангаж, Q/E — рыскание, Space/Shift — тяга, ЛКМ — миниганы (перегрев!),
X — бомба, F — вид от первого лица, 1/2 — сменить дрон, колесо — дистанция камеры.

**Выживший:** ЛКМ — винтовка, ПКМ или V — нож, R — перезарядка, B — режим стройки,
в стройке: ЛКМ — поставить, R — повернуть, 1/2/3 — стена / настил / пандус.

**Всегда:** TAB — таблица счёта. На телефоне — два стика и кнопки «ОГОНЬ» / «БОМБА» / «СТРОЙ» / «ВИД».

## Физика дрона

Не телепортация `CFrame`, а честная динамика:

* тяга — `VectorForce` вдоль локальной оси «вверх» корпуса, гравитация настоящая
  (в крене дрон реально «съезжает» вниз);
* ориентация — `AlignOrientation`, момент масштабируется от массы корпуса;
* аэродинамика — линейное + квадратичное сопротивление `F = -(k1·v + k2·v|v|)`,
  отсюда настоящая максимальная скорость и планирование;
* порывы ветра на `math.noise`, эффект экрана земли, слабеющая тяга на большой высоте,
  урон от жёстких столкновений по Δv;
* сетевые права на физику передаются пилоту (`SetNetworkOwner`), поэтому управление
  без задержки, а урон считает сервер.

Тюнинг — `Config.Physics` в `src/ReplicatedStorage/DroneConfig.luau`.

## Сборка и проверки

```bash
python3 tools/build_place.py      # → VolcanoDrone.rbxlx
python3 tools/validate_place.py   # XML, классы, имена свойств, Ref'ы (0 ошибок)
python3 tools/check_luau.py       # баланс блоков и скобок в скриптах
python3 tools/check_enums.py      # все Enum.* и Instance.new(...) по базе API Roblox
python3 tools/check_order.py      # использование функций до их объявления
```

`tools/` также содержит: бинарный парсер `.rbxl` (`rbxl_reader.py`), XML-писатель (`rbxlx.py`),
импортёр моделей дронов (`drone_import.py`), генераторы карт (`maps.py`, `arena.py`,
`volcano_map.py`).

> Дроны — **модели автора из `hh.rbxl`** (`Беспилотник`, `скинБеспилотник`): импортёр читает
> бинарный плейс, разворачивает их в полётную ориентацию и кладёт в `ServerStorage`.

# Volcano Drone — дроновая аркада над лавовым озером

Готовая игра для Roblox: место `VolcanoDrone.rbxlx` (открывается в Roblox Studio)
плюс исходники Luau в `src/` и вся сборка в `tools/`.

## Быстрый старт

1. Откройте `VolcanoDrone.rbxlx` в Roblox Studio (File → Open from File).
2. Нажмите **Play** — вы сразу в дроне над лавовым каньоном.

## Что внутри

| Элемент | Где | Описание |
|---|---|---|
| `VolcanoDrone.rbxlx` | корень | собранное место: арена, дроны, скрипты, свет |
| `src/ReplicatedStorage/DroneConfig.luau` | ReplicatedStorage → `DroneConfig` | вся настройка: физика, дроны, оружие, враги, волны |
| `src/ServerScriptService/DroneServer.server.luau` | ServerScriptService → `DroneServer` | авторитетный сервер: спавн, урон, враги, турели, бонусы, волны |
| `src/StarterPlayer/StarterPlayerScripts/DroneClient.client.luau` | StarterPlayerScripts → `DroneClient` | клиентская физика полёта, камера, эффекты, ввод |
| `src/StarterPlayer/StarterPlayerScripts/DroneUI.luau` | StarterPlayerScripts → `DroneUI` | HUD, прицел, тач-управление (собирается кодом) |

Дроны **авторские**: обе модели (`Беспилотник` и `скинБеспилотник`) взяты из
исходного `hh.rbxl`, развёрнуты в полётную ориентацию (нос — вперёд, шасси — вниз)
и положены в `ServerStorage`. Сервер выдаёт копию игроку, клиент собирает
физический контроллер и получает сетевое владение (`SetNetworkOwner`).

## Управление

| Клавиши | Действие |
|---|---|
| W / S | тангаж (нос вниз / вверх) |
| A / D | крен (влево / вправо) |
| Q / E | рыскание |
| Space / Shift | тяга вверх / вниз |
| мышь | обзор камеры |
| ЛКМ | миниганы (перегрев!) |
| X | бомба (только «скинБеспилотник») |
| F | вид от первого лица |
| 1 / 2 | сменить дрон |
| колесо | приблизить / отдалить камеру |
| R | сброс после потери дрона |

На телефоне: левый стик — крен/тангаж, правый — рыскание/тяга, кнопки «ОГОНЬ» и «БОМБА».

## Физика полёта (не «телепортация CFrame»)

* тяга — `VectorForce` вдоль локальной оси «вверх» корпуса, гравитация настоящая;
* ориентация — `AlignOrientation` с `MaxTorque`, масштабированным от массы;
* сопротивление воздуха линейное + квадратичное (`F = -(k1·v + k2·v|v|)`), поэтому
  есть честная максимальная скорость и планирование;
* порывы ветра на `math.noise`, эффект экрана земли у поверхности,
  инерция разгона/торможения и повреждения от жёстких столкновений.

Тюнинг — в `Config.Physics` (максимальный крен, скорость рыскания, сопротивления,
ветер, эффект земли).

## Арена

Центральный остров с лавовыми водопадами, каменный мост через лавовое озеро к
замку, семь парящих островов на цепях, шесть турельных башен, площадки-маяки,
бонусы (ремонт / боеприпасы / щит) и вывески «VOLCANO OBBY» / «DANGER LAVA!».
Лава светится (Neon + PointLight), небо — оранжевая дымка с `Atmosphere` и `Bloom`.

## Пересборка места

```bash
python3 tools/build_place.py      # → VolcanoDrone.rbxlx
python3 tools/validate_place.py   # проверка XML и свойств по базе Roblox API
python3 tools/check_luau.py       # баланс блоков в скриптах
python3 tools/check_enums.py      # все Enum.* и Instance.new(...) сверяются с API
```

`tools/` также содержит самописный бинарный парсер `.rbxl` (`rbxl_reader.py`),
импортёр моделей дронов (`drone_import.py`), генератор арены (`arena.py`,
`volcano_map.py`) и XML-писатель (`rbxlx.py`).
